# Object Icon Attribution

The SVG object icons in this directory are from **Twemoji** (the open-source
emoji set originally developed by Twitter, now maintained by the community),
the same icon set distributed on svgrepo.com as the "Twemoji Emojis"
collection.

- Source repository: https://github.com/jdecked/twemoji
- Graphics license: **CC-BY 4.0** — https://creativecommons.org/licenses/by/4.0/
- Copyright: Twitter, Inc and other contributors

The files were renamed from their Unicode codepoint filenames to descriptive
object names (e.g. `1f34e.svg` → `apple.svg`) and given explicit
`width`/`height` attributes; the artwork itself is unmodified.

Attribution is required if you redistribute or publicly deploy this project
with these graphics. Keeping this file in the repository and deployment
satisfies that requirement.
